# Project Rules

Build an AI-native autonomous networking platform capable of:

- detecting anomalies
- performing root cause analysis
- recommending remediation
- visualizing topology
- simulating network behavior

## Coding Principles

Always prefer readability.

Never duplicate logic.

Every API must be typed.

Every endpoint documented.

Avoid global state.

Functions under 60 lines whenever practical.

Use async APIs.

Prefer composition.

---

## Documentation Rules

Whenever architecture changes:

Update docs.

Whenever API changes:

Update api.md.

Whenever schema changes:

Update database.md.
